# 점수 산출 전 목표 보완: V1.1

모델 점수를 계산하기 전에 Lane C의 의미를 구체화했다. 초기 계약과 V1의 구간 설정은 변경 경위로 남기고, 실제 점수에는 아래 V1.1 정의를 적용했다.

- A/B는 공시 원문의 GAAP diluted 분기 EPS를 직접 사용한다. 없는 Q4를 정답으로 합성하지 않는다.
- C는 fiscal Q+4 시점의 TTM을 예측한다. 최초 공시 native ledger에서 기존 PE 엔진의 선택 우선순위인 연간 직접 값 → 직접 관측한 네 분기 → 근사임을 표시한 연간+현재 YTD−전년 YTD를 따른다.
- 실제 미래 네 분기의 합은 별도의 엄격한 경로 진단으로 남긴다.
- 가중평균 주식 수가 달라 연간 diluted EPS와 네 분기의 합은 일치하지 않을 수 있다. C 점수와 PE 연결에는 계산 방식·근사 여부가 함께 있어야 한다.

SEC 전체 snapshot을 이전 엔진에 한 번에 넣으면 후속 공시의 태그 충돌 때문에 회사의 이전 이력까지 거부될 수 있었다. native ledger는 각 시점까지 알려진 prefix로 상태를 복원한다. 전체 엔진의 캐시 이벤트는 독립 대조 자료이며 입력이나 통과 조건이 아니다. 기존 PE 엔진의 선택 우선순위와 운영 계산은 바꾸지 않았다.

첫 데이터 구성에서 split 열을 기존 엔진의 `stock_split` 대신 `split_ratio`로 넘긴 연결 오류도 점수 산출 전에 수정했다. 초기 manifest와 실패 근거는 따로 보존했다. 성과를 보고 목표를 바꾼 수정이 아니다.
