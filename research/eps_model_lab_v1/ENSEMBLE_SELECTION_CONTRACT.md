# V1 ensemble 선택 규칙

기본 모델의 학습·추론 구간과 사전 후보 설정은 유지한다. 연구 평가 결과로 기본 모델의 매개변수를 조정하지 않는다.

2022년 이후 적용할 ensemble에는 2019–2021의 시간순 OOF 예측 중 label이 **2022-01-01 00:00 UTC 이전에 공개된 행**만 쓴다. origin이 2021년이어도 Q+4 label이 그때 가용한 것은 아니다. 각 horizon을 따로 제거한다.

2019–2021 origin 전체의 설명용 평가표와 선택용 표는 다르다. 선택에는 `EPS_SELECTION_LEADERBOARD_V1.csv`를 사용한다. 연구 평가 구간의 정답은 후보·가중치 선정에 쓰지 않는다. 구성원, 예측 해시, 학습 표본 ID와 비음수 가중치를 먼저 고정한다. 가중치를 맞춘 행의 성적을 OOS ensemble 성적으로 보고하지 않는다.

로컬 모델과 사전학습 이력의 과거 중첩 여부가 해결되지 않은 foundation 혼합 모델은 별도 비교군이다. 어느 쪽도 정식 성과 인증을 뜻하지 않는다.

## 결합 방식

목표·비교군마다 cutoff 이전에 가용한 OOF truth를 모두 유한하게 예측하고 최소 100개 정답을 확보한 후보만 사용한다. 과거 보간 격자 대조군 다섯 개는 제외한다.

MAE·MedianAE·가격으로 나눈 MAE의 percentile rank 평균을 후보 점수로 쓴다. 첫 구성원은 최소 점수, 이후 구성원은 이 점수에 기존 구성원과의 최대 절대 잔차상관 × 0.15를 더한 값으로 고른다.

서로 다른 예측을 내는 구성원은 정확히 5개다. 큰 구조 계열당 최대 2개, 같은 foundation checkpoint 계열당 최대 1개이며 동점은 이름순이다. 같은 OOF 예측 벡터는 독립 구성원으로 세지 않는다. 좁은 범위의 specialist는 전체 범위 모델과 따로 평가한다.

고정 평균·중앙값·20% 절사 평균과 비음수 L1 stacking을 계산한다. 절사는 다섯 값 중 양 끝 하나씩을 제거한다. stacking은 가중치 합 1, 절편 없음이며 적격 OOF의 원시 EPS 절대오차만 최소화한다. 평가 결과로 가중치를 다시 맞추지 않는다. 추론 시 다섯 값이 모두 있어야 하며 일부 성공 모델로 재정규화하지 않는다.

최종 파일에는 2022년 이후 연구 평가 origin의 예측만 넣는다. 검증 행은 선정·가중치 학습에 쓰였으므로 성적을 채우지 않는다. 별도 nested 검증은 각 시점 전에 공개된 label만으로 구성원과 가중치 모두 다시 선택해야 하며 최종 파일의 검증 행을 대신하지 않는다.

후보 간 상관과 독립적인 달력 구간 부족, 다중비교·생존편향·데이터 빈티지 한계가 남아 있다. 기존 예측과 실패 기록을 보존하고 점수에 맞춘 미세 조정을 하지 않는다.
